Fixion benchmark research (preliminary): a single self-contained `index.html` with sourced research on LLM benchmarks, LLM-as-judge and X (Twitter) practitioner findings, plus a cutscene-directing benchmark design and 26 seed cases.
Korean version: `ko/index.html` (한국어; same content, linked from the English | 한국어 switch at the top of each page).
Open `index.html` directly (file://) or serve this folder (`python3 -m http.server`); it makes no external requests, and `cases.json` holds the same case data in machine-readable form.
Generated by `tools/build_all.py` in the parent research folder; Fixion was previously called "Dynamic RPG" (code repo: github.com/imaginalnika/dr-dr).
The Korean page is built by the same script through `tools/i18n/ko.py` (translated report `tools/i18n/report_main.ko.md`, case strings `ko_cases.json`, source notes `ko_sources.json`); `cases.json` stays English and machine-readable.
