NEWEpisode-trail heading document

Model: Nemotron-3-Ultra base via Tinker (tag …/heading)

Few-shot genre examples + this world's bios + a tale whose scenes are the trail so far, then the player line (refresh only), the portal-step beat, and a prefilled next heading "N. INT. " / "N. EXT. " for the model to complete.

Scene-block template (code)

f"{i}.  {sc['ie']}  {sc['place_head']}\n\nCHARACTERS: {', '.join(sc['cast']) or 'none'}\n\n"
+ ''.join(f"△ {b.rstrip('.')}.\n" for b in sc['beats'] if b)

IE rule

descent → INT.; climb/edge → EXT.; door into → INT.; other doors flip the previous scene's INT./EXT.

Model: Jev (type choice over candidate headings)

After Nemotron samples up to 7 headings and filters empties / already-seen / portal-name-only / not-a-place, Jev picks the most plausible specific new place among the rest.

Template (expand_v2.JEV_PICK)

The player was in {prev}. {beat} Earlier player line: {action}. Which of these scene headings names the most plausible and specific NEW place for them to arrive in next, through that exact way (a stair down leads somewhere below, a door leads in or out, a climb leads up, an edge leads further on), and fits the player line if there is one?

NEWJev is-it-a-place question (JEV_PLACE)

Model: Jev (noul; keep if ≥ 0.5)

Per surviving candidate heading: does it name a place someone could stand in, or only a time/weather/person/event/feeling?

Does the scene heading "{t}" name a place someone could stand in (a room, building, street, cave, forest, rooftop...)? Answer no if it names only a time, weather, a person, an event or a feeling.
